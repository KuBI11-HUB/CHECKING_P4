# GRANTED UI brief

Product: Scholarship compliance monitoring for University of Luzon (office tool).
Users: Admin (tables, review, rules) and Scholar (status, upload, notifications).
Stack: PHP pages, shared header/footer, assets/css/style.css, assets/icons/*.svg

Brand (locked):
- Maroon #A8180D, gold #C79900, bg #F7F7F7, surface #FFF, text #171717
- Header: maroon bar + thin gold line
- Not a consumer app, not a file-manager clone, not a marketing landing page

Hard rules:
- No rule engine / schema / renewal / mail behavior changes
- No multi-account, no AI-slop gradients, no SaaS metric hero widgets
- Local SVGs only from assets/icons/
- Distinctive but institutional: readable tables first, decoration second
